    Monitoring SADIE¶

    Architecture¶

    Le système de monitoring de SADIE est basé sur la stack suivante : - Prometheus : Collecte et stockage des métriques - Grafana : Visualisation et alerting - Node Exporter : Métriques système - Redis Exporter : Métriques Redis

    Métriques Collectées¶

    Métriques de Trading¶

    1. Trades Traités
    2. Métrique : sadie_trades_processed_total
    3. Type : Counter
    4. Labels : exchange, symbol

    5. Description : Nombre total de trades traités

    6. Latence de Traitement

    7. Métrique : sadie_trade_processing_seconds
    8. Type : Histogram
    9. Labels : exchange, symbol
    10. Buckets : [0.001, 0.005, 0.01, 0.05, 0.1, 0.5]

    11. Description : Temps de traitement des trades

    12. Taille des Buffers

    13. Métrique : sadie_trade_buffer_size
    14. Type : Gauge
    15. Labels : exchange, symbol
    16. Description : Nombre de trades en attente de traitement

    Métriques Réseau¶

    1. Latence Réseau
    2. Métrique : sadie_network_latency_seconds
    3. Type : Gauge
    4. Labels : exchange

    5. Description : Latence des requêtes vers les exchanges

    6. Erreurs Réseau

    7. Métrique : sadie_network_errors_total
    8. Type : Counter
    9. Labels : exchange, type
    10. Description : Nombre d'erreurs réseau par type

    Métriques Cache¶

    1. Cache Hits/Misses
    2. Métriques :
      • sadie_cache_hits_total
      • sadie_cache_misses_total
    3. Type : Counter
    4. Labels : type

    5. Description : Performance du cache

    6. Taille du Cache

    7. Métrique : sadie_cache_size_bytes
    8. Type : Gauge
    9. Labels : type
    10. Description : Utilisation mémoire du cache

    Métriques Système¶

    1. Utilisation Mémoire
    2. Métrique : sadie_memory_usage_bytes
    3. Type : Gauge

    4. Description : Utilisation mémoire du processus

    5. Utilisation CPU

    6. Métrique : sadie_cpu_usage_percent
    7. Type : Gauge
    8. Description : Utilisation CPU du processus

    Configuration Alertes¶

    Alertes Critiques¶

    1. Latence Élevée 

      alert: HighTradeProcessingLatency
expr: histogram_quantile(0.95, rate(sadie_trade_processing_seconds_bucket[5m])) > 0.1
for: 2m

    2. Buffer Plein 

      alert: TradeBufferNearCapacity
expr: sadie_trade_buffer_size > 8000
for: 1m

    3. Erreurs Réseau 

      alert: HighNetworkErrorRate
expr: rate(sadie_network_errors_total[5m]) > 1
for: 5m

    Alertes Warning¶

    1. Cache Performance 

      alert: LowCacheHitRatio
expr: rate(sadie_cache_hits_total[5m]) / (rate(sadie_cache_hits_total[5m]) + rate(sadie_cache_misses_total[5m])) < 0.7
for: 10m

    2. Mémoire 

      alert: HighMemoryUsage
expr: sadie_memory_usage_bytes > 1e9
for: 5m

    Maintenance¶

    Rétention des Données¶

    • Prometheus : 15 jours
    • Grafana : Agrégation après 24h

    Backup¶

    • Snapshots Grafana quotidiens
    • Backup Prometheus hebdomadaire

    Bonnes Pratiques¶

    1. Labels
    2. Limitez le nombre de labels

    3. Évitez les labels à haute cardinalité

    4. Métriques

    5. Préfixez toutes les métriques avec sadie_

    6. Utilisez des unités SI (secondes, bytes)

    7. Alertes

    8. Configurez des délais appropriés
    9. Évitez les faux positifs
    10. Documentez les actions de remédiation
